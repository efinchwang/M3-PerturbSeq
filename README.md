# M3 Perturb-seq

Clean implementation of the final M3 Perturb-seq model developed on the
Jiang et al. TGF-beta Perturb-seq dataset.

The repository contains:

- a pinned M3 fork with sample-level reference/query batch handling;
- the final model architecture;
- standalone training and evaluation entry points;
- tests for reference/query supervision and gradient semantics;
- minimal provenance for the frozen development winner.

The full exploratory/autonomous experiment history is intentionally kept
outside this repository in the original research workspace.
